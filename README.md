# starter-project

Repositori privat sebagai titik awal proyek baru.

## Memulai

```bash
git clone https://github.com/frznst/starter-project.git
cd starter-project
```

## Alur kerja

- Buat branch dari `main` untuk setiap perubahan: `git switch -c fitur/nama-fitur`
- Commit kecil dengan pesan yang jelas
- Buka pull request: `gh pr create`
